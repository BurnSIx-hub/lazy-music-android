# Что нового

Раздел версии уходит на страницу выпуска на GitHub, в плашку «Новая версия»
(первая строка) и в карточку «Что нового?» при первом запуске после
обновления. Тексты пишет пользователь.

## 1.11.1

- Добавил возможность искать треки в самом плейлисте
- Теперь в поиске в первую очередь показывает трек, который уже есть в плейлисте
- Исправил ошибку: при нажатии «Назад» теперь не сбрасывается поиск
- Добавил бегущую строку для длинных названий треков
- Улучшил импорт для «The», иероглифов, специальных знаков и приписок типа «(из фильма)». То, что не нашлось в прошлый раз, должно повторно начать искаться
- Исправлена очередная ошибка 403 (это не точно)

## 1.11.0

- Добавил возможность импортировать треки с Яндекс Музыки сюда
- Изменил оформление некоторых элементов интерфейса
